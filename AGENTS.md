## Shipping

Work on a branch and open a PR; merging to `main` deploys abstract.dannyobrien.dev. Before the PR, verify the change and attach its screenshots and video to the PR (`docs/agents/verify.md`), and review it with `/code-review main`, which enforces `CODING_STANDARDS.md`.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (danmcfan/abstract) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`. The vision board (`docs/vision/board.html`) is the reference for the look, Bitbox and the story.
