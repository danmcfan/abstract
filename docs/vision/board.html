SH 12

The way out

The finale is a program in the language you invented. Short enough to type by hand, meaningful because you built every layer it runs on.

; escape.asm
      LOAD R1, 0x0B0B  ; door code
      OUT  R1, DOOR    ; send to lock
wait: IN   R2, DOOR
      JZ   R2, wait    ; until it clicks
      HALT

The door code could be hidden in notes scattered across earlier levels. The final run plays out at the clock speed you built, so a slow CPU means a tense wait.
